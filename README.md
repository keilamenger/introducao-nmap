# 🔍 Introdução ao Nmap

## 📌 Sobre o projeto

Este projeto apresenta uma introdução ao Nmap, uma ferramenta utilizada para descoberta de hosts, identificação de portas abertas e análise de serviços em redes.

O projeto foi desenvolvido como parte do meu processo de aprendizagem em Cibersegurança.

## 🎯 Objetivos

- Compreender o conceito de endereço IP;
- Entender o que são portas de rede;
- Conhecer o conceito de serviços;
- Conhecer o funcionamento básico do Nmap;
- Realizar um laboratório introdutório em ambiente autorizado;
- Documentar os resultados obtidos.

## 🧠 Conceitos estudados

### Endereço IP

Um endereço IP é utilizado para identificar um dispositivo em uma rede.

Exemplo:

`127.0.0.1`

O endereço `127.0.0.1` representa o próprio computador, sendo conhecido como localhost.

### Portas

Portas são utilizadas para diferenciar serviços e aplicações que utilizam uma conexão de rede.

Alguns exemplos conhecidos:

| Porta | Protocolo/Serviço |
|---|---|
| 22 | SSH |
| 53 | DNS |
| 80 | HTTP |
| 443 | HTTPS |

### Nmap

O Nmap (Network Mapper) é uma ferramenta de código aberto utilizada para descoberta de rede e auditoria de segurança.

Neste projeto, os testes serão realizados somente em ambiente próprio e autorizado.
